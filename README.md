# LuaSTG-Flux Definitions

Definitions for the [LuaSTG-Flux](https://github.com/RulHolos/LuaSTG-Flux) game engine.

This definition addon does contain api for previous engines, but as this addon is made to target LuaSTG-Flux only, some of these might not work for previous or future engine branches.

## Fair warning

While this is feature complete to what the engine itself exposes (so no steam api, sorry), some functions MIGHT be documented incorrectly at the moment.<br>
This is a big task to document this whole engine, and so I did as much as I could in as little time as I could, so I might have brushed over some functions or errors.

As such, this addon will be updated a lot, and everytime a new Flux version comes out with new bindings to add.
